# Chetana Assurance Evidence

This directory contains machine-readable evaluation evidence for Chetana.

## Current Evidence

- `chetana-regression-v0.1.json` is a seven-case curated regression smoke report.
- `chetana-regression-v0.1.mirrorproof.json` binds the exact suite and report digests to the current Chetana MirrorProof issuer key.

## Proof Boundary

The signed statement cryptographically binds the named deterministic regression suite, its recorded report, and the current Chetana issuer key. It does not prove that the run was independently observed, nor does it prove population-level scam detection accuracy, field efficacy, sender authenticity, prevented loss, or independent validation.

Public performance claims require a versioned, adjudicated holdout with representative scam and benign cohorts, per-language slices, confidence intervals, and an assessor independent of the front-line developers.
